Obolus API Basic Examples

Minimal payroll and salary comparison demos

A very slim example repo for the public Obolus API. It shows how to call /api/berechne and /api/taxcompare from a tiny frontend.

API settings

Local development uses the Vite proxy at /api. If you deploy this demo on another domain, you will need a same-origin proxy or API-side CORS support.
